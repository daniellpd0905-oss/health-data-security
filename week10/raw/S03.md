# S03 ｜ IETF RFC 9700

Best Current Practice for OAuth 2.0 Security

- 原始文件：<https://www.rfc-editor.org/rfc/rfc9700.html#section-2.3>
- 原文定位：查 §2.3 Access Token Privilege Restriction，讀資源伺服器、資源與動作的段落。
- 用途：這是已查閱原文後撰寫的繁體中文導讀，供你回到原文取材。請在執行 ingest 時另存自己的來源卡與檢查結果。

## 原文重點（改寫）

存取權杖的權限應盡量縮小到應用所需。可以限制權杖可以交給哪個服務、能對哪些資源做哪些動作，接收端須檢查請求是否符合限制。

## 適用界線與教學提醒

該節足以支持權杖範圍限制。虛構核准單的三天期限另有案例依據。若要介紹特定權杖到期設定，應另找對應章節或明列為案例決策。

## 讀完請回答

一枚權杖可用於摘要服務，是否代表同時能操作其他服務？
