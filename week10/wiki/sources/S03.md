# S03｜存取權杖的權限範圍

IETF，Best Current Practice for OAuth 2.0 Security，RFC 9700（2025），§2.3 Access Token Privilege Restriction。[官方原文](https://www.rfc-editor.org/rfc/rfc9700.html#section-2.3)

**原文支持。** 存取權杖（access token）是程式向服務出示的憑證。權限應限於用途所需，接收端應核對適用服務、目標資源及操作。

**適用界線。** 本節支持限制服務與動作。三天是 CASE 中的研究授權期間，個別權杖的到期時間需查其設定。
