# S03 第一版｜作者已通過

| 審核項目 | 送審內容 |
|---|---|
| 原文位置 | 網際網路工程任務組（IETF），Best Current Practice for OAuth 2.0 Security，RFC 9700（2025 年 1 月），§2.3 Access Token Privilege Restriction。[官方原文](https://www.rfc-editor.org/rfc/rfc9700.html#section-2.3) |
| 白話主張 | 存取權杖（access token）是程式向服務提出請求時出示的憑證。權杖權限應限於任務所需，可限制接收服務、資源與操作。服務收到請求時應檢查它是否落在授權範圍內。 |
| 適用界線 | 此節說明權限範圍。grant-017 的三天是研究申請的核准期間。單枚權杖的有效時間需另有設定依據。 |
| 預計更新 | W02 加入「權杖尚未到期，可以拿來匯出嗎？」。教材以假設的唯讀權杖示範，將 S03 技術原則與 CASE 的授權單條件分開。 |

例句：假設權杖仍有效，但只允許摘要服務讀取指定資料。用它請求匯出時，摘要服務應拒絕，因為匯出超出允許的操作。
