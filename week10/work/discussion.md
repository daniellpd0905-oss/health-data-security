| 對話中的問題 | 作者回覆 | 採用的做法 |
|---|---|---|
| Wiki 首頁先看授權單或先看可查詢的主題？ | B | 以存取申請與審核、身分與權限、存取稽核紀錄為三個主題入口，簡報則依案例順序教學。 |

## 九題訪談與最終確認

| 題目 | 作者採用的做法 |
|---|---|
| 1．用途 | B，本週完成一個案例，其知識可供期末 Agent 引用。 |
| 2．教學起點 | B，對照原始申請與核准內容。沿用上週授權單作為既有案例。 |
| 3．名詞 | B，首次出現提供白話解釋和例子。 |
| 4．範圍 | A，以合成資料教授權與稽核，法規細節另題處理。 |
| 5．練習 | B，每次只改一項條件。 |
| 6．矛盾 | A，列出矛盾主張及出處，由作者決定。 |
| 7．查詢回寫 | B，經核對的常見問題補回主題頁。 |
| 8．互動 | B，讀者先選判斷，再看理由。 |
| 9．流程證據 | B，首頁提供製作流程與實測入口，保留詳細紀錄。 |
